# جلسه دوم طراحی سایت با هوش مصنوعی

ارائه تعاملی فارسی و راست‌چین برای جلسه دوم دوره «طراحی سایت با هوش مصنوعی و Vibe Coding» با عنوان «ساخت مغز پروژه برای هوش مصنوعی».

## مشاهده آنلاین

[باز کردن ارائه جلسه دوم](https://pishgard.github.io/vibe-coding-session-2/)

## کنترل‌ها

- کلیدهای جهت‌دار: اسلاید قبلی و بعدی
- `O`: نمای کلی
- `N`: یادداشت مدرس
- `F`: حالت تمام‌صفحه
- لمس یا Swipe: جابه‌جایی روی موبایل

## موضوعات جلسه

Markdown، ساختار فایل‌های دستور، `agent.md`، `rules.md`، `skill.md`، `task.md`، `context.md`، ترتیب خواندن فایل‌ها و تمرین ساخت نسخه اول سایت با یک سیستم منظم از دستورها.

نام فایل‌ها در این ارائه یک قرارداد آموزشی برای کلاس است و ممکن است ابزارهای مختلف نام‌ها یا ساختار دیگری داشته باشند.
