# جلسه دوم طراحی سایت با هوش مصنوعی

ارائه تعاملی فارسی و راست‌چین برای جلسه دوم دوره «طراحی سایت با هوش مصنوعی و Vibe Coding».

## مشاهده آنلاین

[باز کردن ارائه جلسه دوم](https://pishgard.github.io/vibe-coding-session-2/)

## کنترل‌ها

- کلیدهای جهت‌دار: اسلاید قبلی و بعدی
- `O`: نمای کلی
- `N`: یادداشت مدرس
- `F`: حالت تمام‌صفحه
- لمس یا Swipe: جابه‌جایی روی موبایل

## موضوعات جلسه

HTML، تگ‌ها، ساختار صفحه، CSS، Selector، Class، Box Model، Flexbox، طراحی واکنش‌گرا، پرامپت‌نویسی دقیق، بررسی خروجی هوش مصنوعی و تمرین شخصی‌سازی سایت.
